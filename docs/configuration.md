# Configuration

All configuration comes from environment variables. Two templates are meant to be tracked:

| Template | Real file (git-ignored) | Consumed by |
|---|---|---|
| `.env.example` | `.env` (generated by `make setup` / `scripts/setup.sh`) | Docker Compose → every service |
| `infra/terraform/.env.example` | `infra/terraform/.env` (copy and edit) | `infra/terraform/scripts/terraform-env.sh` → `TF_VAR_*` |

`scripts/setup.sh` copies the template and replaces every `<generated>` value with output of
`openssl rand` (or Python `secrets`). It prints the admin and Grafana passwords **once**. Rotate:
`scripts/setup.sh --reset-admin-password`, `scripts/rotate-token-key.sh`.
`scripts/validate-config.sh` (run by `make up`) checks for missing keys and unfilled placeholders.

The backend validates everything with Pydantic at startup and refuses to start on missing or unsafe
values: secrets shorter than 32 bytes (16 in development/test), placeholder values, `COOKIE_SECURE=false`
in production, `HEARTBEAT_TIMEOUT_SECONDS` not above twice the poll interval, malformed backend URLs or
key lists. The frontend validates its server-side values per request (`src/lib/env.ts`).

## Root `.env`

| Variable | Default | Purpose |
|---|---|---|
| `APP_ENV` | development | development, test, staging, production |
| `LOG_LEVEL` | INFO | JSON logs on stdout |
| `BIND_ADDRESS` | 127.0.0.1 | Host interface for published ports |
| `PROTECTED_PORT` / `DIRECT_PORT` | 8080 / 8081 | Protected and unprotected (local only) entry points |
| `FRONTEND_PORT` / `GRAFANA_PORT` / `PROMETHEUS_PORT` | 3000 / 3001 / 9090 | Console, Grafana, Prometheus |
| `API_HOST` / `API_PORT` | 0.0.0.0 / 8000 | API bind inside its container |
| `REDIS_URL`, `REDIS_PASSWORD`, `REDIS_KEY_PREFIX`, `REDIS_MAXMEMORY` | | Redis connection and key namespace |
| `ADMISSION_RATE` | 10 | Visitors admitted per second (token bucket refill) |
| `ADMISSION_BURST` | 10 | Bucket capacity |
| `MAX_ACTIVE_ADMITTED` | 0 | Cap on valid tokens (0 = off) |
| `QUEUE_MAX_SIZE` | 100000 | Joins beyond this get 503 `queue_full` |
| `QUEUE_POLL_INTERVAL_SECONDS` | 3 | Waiting-room poll interval (each poll = heartbeat) |
| `HEARTBEAT_TIMEOUT_SECONDS` | 30 | Waiting visitors without heartbeat are expired |
| `REJOIN_GRACE_SECONDS` | 60 | Window in which an expired visitor keeps their place |
| `VISITOR_RECORD_TTL_SECONDS` | 86400 | Lifetime of visitor records and the `sg_vid` cookie |
| `WORKER_TICK_SECONDS` / `WORKER_LOCK_TTL_SECONDS` | 0.5 / 5 | Worker loop and leader lock |
| `WAIT_ESTIMATE_WINDOW_SECONDS` / `WAIT_ESTIMATE_MIN_SAMPLES` | 60 / 5 | Measured-throughput window for estimates |
| `BACKEND_URLS` | demo-1, demo-2 | Origins (Nginx upstreams and active checks are both rendered from this) |
| `BACKEND_HEALTH_*` | path /health, 2 s, 1 s timeout, 2 / 2 | Active health checks and hysteresis |
| `TOKEN_TTL_SECONDS` | 300 | Admission token lifetime (reusable for the whole TTL) |
| `TOKEN_SIGNING_SECRET`, `TOKEN_SIGNING_KID`, `TOKEN_VERIFY_KEYS` | generated, k1, empty | Active key and retired keys (`kid:secret,...`) |
| `TOKEN_ISSUER` / `TOKEN_AUDIENCE` | | JWT `iss` / `aud` |
| `VISITOR_COOKIE_SECRET` | generated | HMAC for the visitor id cookie |
| `COOKIE_SECURE` | false | `Secure` cookie flag; must be true behind HTTPS and in production |
| `INTERNAL_AUTH_SECRET` | generated | Nginx → `/internal/auth` trust |
| `ORIGIN_SHARED_SECRET` | generated | Nginx → origin trust (`X-Origin-Key`) |
| `ADMIN_API_KEY` | generated | Console server → admin API |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD_HASH` | admin / bcrypt | Single operator login |
| `SESSION_SECRET` / `SESSION_TTL_SECONDS` | generated / 28800 | Console session JWT |
| `LOGIN_RATE_LIMIT_ATTEMPTS` / `_WINDOW_SECONDS` | 5 / 300 | Login throttling |
| `REVIEWER_LOGIN_ENABLED` / `REVIEWER_USERNAME` / `REVIEWER_PASSWORD` | true / reviewer / generated | Shareable **full-permission** login for reviewers. Password generated by `setup.sh`, kept in `.env`, never shown in the UI. Development/test only |
| `DEMO_LOGIN_ENABLED` / `DEMO_ROLE` / `DEMO_USERNAME` / `DEMO_PASSWORD` | true / admin / demo / surgeguard-demo | Demo account with **public** credentials and a one-click button on the login page. `DEMO_ROLE=admin` = full permissions, `viewer` = read-only. Refused (config error) unless `APP_ENV` is development or test |
| `RATE_LIMIT_REQUESTS` / `RATE_LIMIT_WINDOW_SECONDS` | 2000 / 60 | App-level joins per IP |
| `PROXY_RATE_LIMIT_RPS` / `_BURST` | 500 / 1000 | Nginx per-IP limit on all public routes |
| `PROXY_JOIN_RATE_LIMIT_RPS` / `_BURST` | 50 / 300 | Nginx per-IP limit on joins |
| `CACHE_TTL_SECONDS` | 60 | Static asset cache lifetime |
| `PROXY_CONNECT_TIMEOUT_SECONDS` / `PROXY_READ_TIMEOUT_SECONDS` / `PROXY_AUTH_TIMEOUT_SECONDS` | 2 / 15 / 2 | Upstream timeouts |
| `DEMO_MAX_CONCURRENCY` / `DEMO_WORK_MS` / `DEMO_QUEUE_TIMEOUT_MS` | 8 / 150 / 1500 | How fragile the demo origin is |
| `API_INTERNAL_URL`, `PROMETHEUS_URL` | | Server-side URLs used by the console |
| `PUBLIC_SITE_URL`, `PUBLIC_GRAFANA_URL` | | Links shown in the console |
| `METRICS_ENABLED` | true | Expose `/metrics` |
| `GRAFANA_ADMIN_USER` / `GRAFANA_ADMIN_PASSWORD` | admin / generated | Grafana login |

The default limits are sized so that a single-machine k6 run (all virtual users share one IP) is not
throttled. Real deployments behind a shared NAT should keep limits generous for the same reason.

## Terraform `.env`

See `infra/terraform/.env.example` and `variables.tf` (all inputs have validation). The loader parses
the file line by line (no `eval`/`source`), rejects malformed lines and `<placeholders>`, checks the
required keys, exports `TF_VAR_<lowercase key>` and `exec`s Terraform.
